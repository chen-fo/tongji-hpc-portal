# 学生手册（Phase 0 / 1 / 2 / 3）

使用管理员提供的 Portal 用户名和初始密码登录。它是课题组平台身份，与学校的官方 HPC Linux 账号不同。

登录后，“概览”显示自己的 Portal 身份、官方账号 ID 和个人工作目录。“设置”可以修改密码，要求 12–128 个字符；修改完成后所有登录会话会失效，请使用新密码重新登录。

页面右上角的“退出登录”会撤销当前会话。忘记密码或账号被停用时请联系管理员，平台不开放公开注册或邮件找回。

“终端”中点击连接，初始进入个人工作目录，`cd ~` 返回该目录。支持 Ctrl+C/D、Tab 和窗口 resize。连接模式明确标为 Mock 或真实 SSH；Mock 不执行真实科研命令。

管理员记录普通 Bash 命令和执行前目录。请使用程序的隐藏输入提示输入密码，不要把密码或 Token 直接写进命令。页面离开、登录撤销、网络断开或空闲超时会释放终端会话。

真实终端仅对完成验收并由管理员明确开放的身份启用。个人目录不是 Linux 权限隔离。Slurm 任务与预算计费尚未开发。

“文件”页面浏览自己的个人目录，可新建文件夹、上传、下载、重命名与删除。上传显示进度并可取消；下载进度使用浏览器下载列表。目标同名时拒绝覆盖，删除文件夹需确认删除其中全部内容。软链接与特殊文件首版不开放操作，个人根目录不能删除。管理员可将真实文件空间设为只读。

网页文件操作会记录操作信息及结果，不记录文件内容；记录不覆盖通过终端或脚本直接执行的文件操作。取消上传或网络中断后请刷新目录确认结果。更详细的限制见 [文件管理说明](phase3.md)。
